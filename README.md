# Running the prototype pipeline workflow

This document provides instructions for running the prototype pipeline workflow. 


- clone the repository and navigate to the project directory:

```bash
git clone <repository_url>
cd <project_directory>
```

- install the required dependencies and activate the virtual environment:

```bash
uv sync
source .venv/bin/activate
```

- start the prefect server in one terminal:

```bash
prefect server start
``` 

- in a separate terminal, run the `orchestrator.py` script to start the workflow:

> Make sure the new terminal also has the virtual environment activated.

```bash
python orchestrator.py
```

- You can view the status of each task and any logs generated during the run in the terminal.

- Once the workflow has completed, you can check the output files generated by the tasks in the `output` directory.
